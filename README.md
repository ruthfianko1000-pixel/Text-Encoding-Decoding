**Text Encoder and Decoder**

**Project Description**
This project is a Python program that encodes and decodes text using the Caesar Cipher algorithm.
**** Algorithm Used****
Caesar Cipher.
** Programming Language**
Python.
 **Features**
- Encodes text into coded messages.
- Decodes coded messages into their original form.
- Allows users to select a shift number.
- Preserves spaces, numbers and special characters.
** How to Run**
1. Run the Python program.
2. Select Encode or Decode.
3. Enter your text.
4. Enter the shift number.
5. View the result.
